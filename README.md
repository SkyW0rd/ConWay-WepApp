# Игра «Жизнь» Конвея — веб-приложение

Интерактивная симуляция клеточного автомата [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life).  
Бэкенд на **F# / ASP.NET Core**, фронтенд — **HTML, CSS, JavaScript** без сборщиков и фреймворков.

## Быстрый запуск

**Требования:** [.NET 8 SDK](https://dotnet.microsoft.com/download)

```bash
cd "ConWay-WebApp"
dotnet run
```

Откройте в браузере: **http://127.0.0.1:5000**

При первом запуске `dotnet` скачает зависимости NuGet — это нормально.

## Структура проекта

```
ConWay-WebApp/

├── Program.fs           # HTTP API и мост между UI и Life.fs

├── appsettings.json     # Настройки ASP.NET Core

    ├── css/
    │   └── site.css     # Стили (тёмная тема, сетка, панель фигур)
    └── js/
        ├── patterns.js  # Каталог известных фигур
        └── site.js      # Логика UI, API-запросы, отрисовка
```

## Что реализовано

### Ядро (`Life.fs`)

- Бесконечная доска через `Set<Cell>` — координаты не ограничены размером экрана
- Шаг симуляции по классическим правилам B3/S23
- Подсчёт популяции, сдвиг (`translate`), объединение миров
- Загрузка паттернов из текстовых файлов и формата **RLE**
- Генерация случайного поля с заданной вероятностью
- Вывод поля в ASCII для отладки

### Сервер (`Program.fs`)

- Раздача статики из `wwwroot` (`UseDefaultFiles`, `UseStaticFiles`)
- REST API для управления симуляцией:

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/state` | Текущее состояние: размер окна, смещение, поколение, популяция, массив клеток |
| `POST` | `/api/step` | Один шаг симуляции |
| `POST` | `/api/clear` | Очистить поле |
| `POST` | `/api/random` | Случайное заполнение (25 % живых клеток) |
| `POST` | `/api/toggle/{x}/{y}` | Переключить клетку |
| `POST` | `/api/alive/{x}/{y}` | Включить клетку (для расстановки фигур) |

Видимое окно: **40×25** клеток. Логика «бесконечного» поля живёт на сервере; UI показывает текущий фрагмент.

### Веб-интерфейс (`wwwroot/`)

- **Управление симуляцией:** шаг, автозапуск (300 мс), случайное поле, очистка
- **Редактирование:** клик по клетке переключает её состояние
- **Панель фигур:** 17 классических паттернов (блок, планер, пульсар, r-пентамино, ружьё глайдера и др.)
- **Поиск** фигур по названию
- **Drag-and-drop** и клик для размещения фигуры на поле
- **Предпросмотр** (оранжевый) перед постановкой
- **Трансформации черновика:** перемещение стрелками, поворот ↺↻, отражение ↔↕
- **Статистика:** число живых клеток и номер поколения

## Как пользоваться

1. Запустите сервер (`dotnet run`) и откройте http://127.0.0.1:5000
2. Кликайте по клеткам, чтобы рисовать вручную, или нажмите **Случайно**
3. **Старт** / **Стоп** — непрерывная симуляция; **Шаг** — одно поколение
4. Выберите фигуру справа → кликните на поле или перетащите → подгоните положение → **Поставить**
5. **Отмена фигуры** сбрасывает черновик без изменений на поле

## Разработка

- Изменения в `wwwroot/` подхватываются при перезапуске или hot reload (если включён `dotnet watch`)
- Для наблюдения за изменениями без ручного перезапуска:

```bash
dotnet watch run
```

- Новые фигуры добавляются в `wwwroot/js/patterns.js` — массив объектов `{ name, cells }`, где `cells` — список `[x, y]` относительно левого верхнего угла фигуры
